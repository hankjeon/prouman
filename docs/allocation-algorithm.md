# 월별 인력 배분 알고리즘

## 단위와 월 기준

모든 인력 수치는 `Decimal('0.00001')`의 정수배다. 내부 배분에서는 1단위를 `0.00001`로 하는 정수로 다룰 수 있다. 입력 수량을 float로 변환하지 않는다. 나눗셈 후 월 공백 인력에 적용하는 반올림은 `ROUND_HALF_UP`이다.

월 기준 `B_m`은 3·6·9·12월 `0.08334`, 나머지 월 `0.08333`이다. 각 분기 합계는 `0.25000`, 연간 합계는 `1.00000`이다. 윤년과 월 일수는 Python 표준 달력 함수로 오프라인 계산한다.

## 1. 공백과 가용량

> 이 문서는 **확정된 연간 목표를 월별로 배분하는 현재 알고리즘**이다. 후속 [연간 인력 계획 기능](annual-planning.md)은 확정 전 목표의 초안을 생성하며, 이 문서의 월 기준·공백·허용 월·검증을 재사용한다.

관리 연도와 모든 공백 기간을 교집합으로 자르고, 시작·종료일을 포함한다. 서로 겹치는 날짜는 합집합으로 한 번만 센다. 월 `m`의 공백 일수 `D_m`, 월 총일수 `L_m`에 대해:

```text
A_m = quantize(B_m × D_m / L_m, 0.00001, ROUND_HALF_UP)
C_m = B_m - A_m
```

`A_m`은 월 공백 인력, `C_m`은 사업에 배분할 월 가용량이다. 월별로 반올림한 `A_m`을 합쳐 연간 공백량을 만든다. **연간 공백량을 먼저 계산해서 다시 월로 나누지 않는다.** `0 ≤ A_m ≤ B_m`, `0 ≤ C_m ≤ B_m`을 보장한다.

예: 2026년 7월 15~31일 공백은 17/31일이다. `0.08333 × 17/31 = 0.04570`(반올림)이고 7월 가용량은 `0.03763`이다.

## 2. 사업 허용 월

사업 기간 `[start, end]`와 월 `[month_start, month_end]`가 하루라도 겹치면 그 월 전체를 사업 수행 월로 본다. **사업 수행 일수 비례 상한은 적용하지 않는다.** 해당 연도 `excluded_months`에 월이 들어 있으면 수행 월이어도 허용하지 않는다. 허용되지 않는 월은 모든 사람에 대해 `x = 0.00000`이다. 허용 월이어도 해당 사람의 `C_m = 0`이면 그 사람은 그 월에 0만 배분할 수 있다.

## 월별 최소 배정 목표 (2026-11-06 변경)

양수 연간 목표가 있는 사람·사업에 대해, 사업 기간 안이며 제외 월이 아니고 그 사람의 월 가용량이 양수인 각 월에 최소 `0.00010`을 우선 배정한다. 연간 목표 0인 사업, 제외 월·사업 기간 밖, 전체 휴직·퇴직 등으로 가용량이 0인 월은 적용 대상이 아니다.

이 최소치는 필수 제약보다 우선하지 않는다. 연간 목표·월별 합계·허용 월·사업 상한을 지키면서 모든 대상 월에 최소치를 줄 수 있으면 전부 지킨다. 불가능하면 대상 셀별 부족량 `max(0, 0.00010 - x[i,p,m])`의 합을 최소화한 해 안에서 기존 균등 초안에 가까운 값을 선택한다. 한 월의 최소치를 못 지켰다는 이유로 다른 월의 최소치를 일괄 해제하지 않는다. 예외 월에는 `0.00001` 단위의 작은 값과 0을 허용하고, 사람·사업·연도·월·실제 값을 `W006`으로 알린다. 경고만으로 계산을 중단하지 않는다.

최소치 부족량이 같으면 기존의 허용 월 수·사업약칭·월 순서에 따라 초안 편차를 줄인다. 예를 들어 연중 사업 목표가 `0.00060`뿐이면 12개월 각각 `0.00005`가 될 수 있다. 이 경우도 입력 목표를 늘리거나 일부 인력을 만들지 않는다. 반대로 특정 월이 다른 사업의 고정 목표로 전부 차 있으면 그 월만 0일 수 있으며 다른 허용 월은 최소치를 유지한다.

## 3. 필수 제약과 사전 검증

사람 `i`, 사업 `p`, 월 `m`의 할당을 `x[i,p,m]`, 사람의 입력 연간 목표를 `T[i,p]`, 사업의 해당 연도 배정인력 상한을 `U[p]`라고 한다.

```text
x[i,p,m] ≥ 0, 0.00001의 정수배
Σ_p x[i,p,m] = C[i,m]                   (모든 사람·월)
Σ_m x[i,p,m] = T[i,p]                   (입력된 사람·사업 목표 고정)
허용되지 않은 사업·월이면 x[i,p,m] = 0
Σ_i Σ_m x[i,p,m] ≤ U[p]                 (사업별 연간 상한)
```

연간 합계 `Σ_p T[i,p] + Σ_m A[i,m] = 1.00000`을 배분 전 확인한다. 해당 연도 사업 배정정보가 없거나 0인데 `T[i,p] > 0`이면 오류다. 배정인력 미달은 정상이다.

각 사람마다 `사업(공급량 T) → 허용 월(수요량 C)` 이분 그래프의 정수 흐름 문제로 **실제 실행 가능한 해가 있는지** 판정한다. 사업마다 허용 월이 존재하고 단일 사업의 총 허용 월 용량이 목표 이상인지만 확인해서는 부족하다. 여러 사업이 같은 월에 몰리는 충돌까지 확인해야 한다. 최대 흐름이 사람의 연간 가용량에 못 미치면 `ERROR`이며, 허용 월·목표·부족량을 표시한다. 사업 상한은 목표량 합계로 이미 결정되므로 별도로 사전 검증한다.

## 4. 간단한 균등 배분과 조정

`E[i,p]`는 사업 수행·제외 월 조건을 통과하고 그 사람의 `C[i,m] > 0`인 월 집합이다. `T[i,p] > 0`인데 `E[i,p]`가 비면 오류다. 먼저 각 사람·사업 목표를 그 허용 월에 **균등 분할한 초안**을 만든다. 목표 `T`를 `0.00001` 단위 정수로 바꾸고 허용 월 수 `k`로 나누어 몫을 모든 허용 월에 배치한다. 나머지 1단위씩은 빠른 월부터 놓는다. 예를 들어 `0.60000`을 12개월에 배분하면 월 `0.05000`, 9개월에 배분하면 월별 `0.06666` 또는 `0.06667`이 된다.

초안이 사람별 월 가용량과 정확히 맞고 월별 최소 배정 부족량도 최선이면 그대로 사용한다. 맞지 않으면 **연간 목표를 고정한 채** 허용 월 사이에서 값을 옮겨 모든 사업을 함께 조정한다. 허용 월이 적은 사업의 균등 배분을 우선 유지하고, 허용 월이 많은 사업으로 월별 잔여량을 채우는 간단한 방식을 기본으로 한다. 허용 월 수가 같으면 사업 `alias` 오름차순, 나머지 1단위 배치는 빠른 월 순서를 사용한다. 어떤 조정 결과든 3절의 필수 제약과 최소 배정 부족량의 최적값을 유지해야 하고 YAML의 항목 순서와 관계없이 재현되어야 한다.

처리 순서는 사람별 `E[i,p]`의 월 수 오름차순, 앞뒤 공백 제거 후 사업약칭 오름차순, 월 오름차순이다. 먼저 처리한 사업의 균등 초안을 가능한 한 유지하되, 이 우선순위는 사업을 변경 불가능하게 확정하는 규칙이 아니다. 전체 배분을 위해 필요하면 앞선 사업도 재조정한다. 수용 사례 T02·T03의 구체적인 균등 패턴은 유지해야 하며, 해당 사례에서 제약만 만족하는 임의의 최대 흐름 결과로 대체하지 않는다. 일반 입력의 여러 가능한 해 중에서는 이 처리 순서와 고정된 재조정 절차로 재현성을 보장한다.

간단한 균등 분할이나 조정 절차가 실패했다는 이유만으로 `ERROR`를 내지 않는다. 3절의 실행 가능성 검사를 통해 실제로 해가 없을 때에만 배분 불가능으로 판정한다. 해가 있다면 균등 초안을 참고하여 실행 가능한 결과를 찾는다. **제곱편차 최소화, 전역 최적성 증명, 모든 가능한 해의 탐색은 1차 요구사항이 아니다.** 휴직이나 제외 월 등으로 불가피한 월별 차이는 허용한다. 월별 기준이나 입력 연간 목표는 균등화를 위해 변경하지 않는다.

## 5. 사후 검증과 집계

모든 `x`에 대해 비음수·5자리 단위·허용 월 0, 사람·월 정확한 합계, 사람·사업 연간 목표, 사람·분기 `0.25000`(공백 포함), 사람·연간 `1.00000`(공백 포함), 사업별 상한을 다시 계산한다. 합계를 보존하는 재배치로 월별 최소 배정 부족량을 더 줄일 수 없는지도 음수 순환 검사로 검증한다. 실패하면 결과를 출력하지 않고 `ERROR`다. 개인·사업 월간표와 연간표는 최종 `x`와 `A`에서 합산한다. 분기 합계는 내부 검증에만 사용하고 출력 열에는 포함하지 않는다.

사업1을 4~6월 제외하고 사람의 연간 목표가 사업1 `0.60000`, 연중 허용 사업2 `0.40000`, 공백 없음인 경우, 사업1의 나머지 9개월 평균만 독립 계산하면 월 합계가 어긋난다. 4~6월에는 사업2가 월 가용량 전체를 받고, 그 외 월에는 사업1과 사업2가 함께 월 가용량을 채우는 해를 찾는다.

## 구현의 결정적인 재조정 절차

1. 사람별 `사업 → 월` 정수 흐름 그래프를 만든다. 양수 목표의 허용 셀마다 첫 10단위(`0.00010`)에는 비용 -1, 나머지에는 비용 0을 준다. 사람·사업 공급은 고정 연간 목표, 월 수요는 개인 가용량이다. 모든 계산은 정수로 수행한다.
2. 최소 비용 최대 흐름으로 전체 배분 가능성을 판정한다. 전체 가용량을 배분할 수 있는 해 중 첫 10단위의 배정을 최대화하므로 최소치 부족량 합계가 최소가 된다. 최소치 때문에 기존에 실행 가능하던 입력을 `ERROR`로 바꾸지 않는다. 필수 제약을 만족하는 해 자체가 없을 때만 최대 흐름 부족량과 최소 컷의 사업·월을 `E201`로 표시한다.
3. 사업별 몫·나머지 균등 초안을 만든다. 허용 월 수·약칭·월 순서로 셀을 방문해, 앞선 셀을 유지하면서 현재 셀을 초안에 가장 가깝게 조정한다. 잔여 그래프에서 비용 합이 0인 순환만 사용해 최소 배정의 최적값을 보존한다. 경로의 잔여 용량만큼 한 번에 옮긴다. 최소치 경계를 넘으면 비용이 바뀌므로 해당 구간에서 경로를 다시 찾는다.
4. 합계·목표·허용 월·단위·상한을 사후 검증하고, 독립적인 잔여 그래프의 음수 순환 검사로 최소치 부족을 더 줄일 수 없는지 확인한다. 결과가 올바르면 대상 셀 중 `0.00010` 미만인 월마다 `W006`을 만든다.

제곱편차 전역 최적화는 요구하지 않는다. 최소치 부족 최적값 안에서 초안 편차를 셀 순서대로 줄이고 탐색 순서도 고정하므로 YAML 항목 순서와 관계없이 같은 결과를 얻는다. 기존 흐름 함수의 기본 `minimum=0` 동작은 유지하며 월별 계산 엔진에서 `minimum=10`을 명시한다. 후속 계획 기능은 이 엔진의 월별 계산·검증을 재사용해야 한다.
