# 월별 인력 배분 알고리즘

이 문서는 **실적작업**의 이미 구현된 알고리즘이다. 실적은 결정된 연간 할당량을 월별로 나누는 업무이며 실제 월별 근무 기록 입력을 뜻하지 않는다. 2026-11-07 [계획작업 재정의](annual-planning.md)를 소스의 독립 작업 모드·계획 형식·UI에 반영했지만 이 문서의 월별 알고리즘은 변경하지 않았다.

## 단위와 월 기준

모든 인력 수치는 `Decimal('0.00001')`의 정수배다. 내부 배분에서는 1단위를 `0.00001`로 하는 정수로 다룰 수 있다. 입력 수량을 float로 변환하지 않는다. 나눗셈 후 월 공백 인력에 적용하는 반올림은 `ROUND_HALF_UP`이다.

월 기준 `B_m`은 3·6·9·12월 `0.08334`, 나머지 월 `0.08333`이다. 각 분기 합계는 `0.25000`, 연간 합계는 `1.00000`이다. 윤년과 월 일수는 Python 표준 달력 함수로 오프라인 계산한다.

## 1. 공백과 가용량

> 이 문서는 **확정된 연간 목표를 월별로 배분하는 현재 알고리즘**이다. [계획작업](annual-planning.md)은 조건 안에서 연간 목표를 산정·조정하고, 이후 월별 배분도 가능한지 확인하기 위해 같은 월 기준·공백·허용 월·검증을 사용할 수 있다. 계산 규칙 재사용과 두 업무의 독립성은 구분한다.

관리 연도와 모든 공백 기간을 교집합으로 자르고, 시작·종료일을 포함한다. 서로 겹치는 날짜는 합집합으로 한 번만 센다. 월 `m`의 공백 일수 `D_m`, 월 총일수 `L_m`에 대해:

```text
A_m = quantize(B_m × D_m / L_m, 0.00001, ROUND_HALF_UP)
C_m = B_m - A_m
```

`A_m`은 월 공백 인력, `C_m`은 사업에 배분할 월 가용량이다. 월별로 반올림한 `A_m`을 합쳐 연간 공백량을 만든다. **연간 공백량을 먼저 계산해서 다시 월로 나누지 않는다.** `0 ≤ A_m ≤ B_m`, `0 ≤ C_m ≤ B_m`을 보장한다.

예: 2026년 7월 15~31일 공백은 17/31일이다. `0.08333 × 17/31 = 0.04570`(반올림)이고 7월 가용량은 `0.03763`이다.

## 2. 사업 허용 월

사업 기간 `[start, end]`와 월 `[month_start, month_end]`가 하루라도 겹치면 그 월 전체를 사업 수행 월로 본다. **사업 수행 일수 비례 상한은 적용하지 않는다.** 해당 연도 `excluded_months`에 월이 들어 있으면 수행 월이어도 허용하지 않는다. 허용되지 않는 월은 모든 사람에 대해 `x = 0.00000`이다. 허용 월이어도 해당 사람의 `C_m = 0`이면 그 사람은 그 월에 0만 배분할 수 있다.

## 월별 균등 배정과 최소 배정 목표

양수 연간 목표가 있는 사람·사업에 대해, 사업 기간 안이며 제외 월이 아니고 그 사람의 월 가용량이 양수인 월을 균등 배정 대상에 넣는다. 연간 목표 0인 사업, 제외 월·사업 기간 밖, 전체 휴직·퇴직 등으로 가용량이 0인 월은 대상이 아니다. 허용 월 수 `k`와 연간 목표의 5자리 단위 정수 `T`에 대해 `T = kq + r`이면, 각 허용 월에 `q` 또는 `q+1`단위만 배정하는 해를 **모든 사업을 함께 고려해 먼저 탐색**한다. 월별 합계와 사업 상한은 이 탐색에서도 절대 제약이다.

완전 균등 해가 없으면, 양수 목표의 대상 월마다 `0.00010`을 하한으로 지킬 수 있는지 판정한다. 가능하면 그 하한을 지키는 해 중 월별 균등 목표에서의 **가장 큰 편차**를 먼저 최소화하고, 같은 최대 편차의 해에서는 전체 절대 편차를 최소화한다. 이 값은 하한이지 선호하는 배정량이 아니다. 동률에서는 정확히 하한에 머무는 칸 수를 줄인다.

모든 대상 월에 하한을 지킬 수 없다면, 대상 셀별 부족량 `max(0, 0.00010 - x[i,p,m])`의 합을 최소화한 뒤 같은 최대 편차·전체 절대 편차 순서로 균형을 잡는다. 한 월의 하한을 못 지켰다고 다른 월의 하한을 일괄 해제하지 않는다. 예외 월에는 더 작은 값과 0을 허용하고 사람·사업·연도·월·실제 값을 `W006`으로 알린다. 경고만으로 계산을 중단하지 않는다. 예를 들어 연중 사업 목표가 `0.00060`뿐이면 12개월 각각 `0.00005`가 가능하다. 입력 연간 목표나 월별 합계는 변경하지 않는다.

## 3. 필수 제약과 사전 검증

사람 `i`, 사업 `p`, 월 `m`의 할당을 `x[i,p,m]`, 사람의 입력 연간 목표를 `T[i,p]`, 사업의 해당 연도 배정인력 상한을 `U[p]`라고 한다.

```text
x[i,p,m] ≥ 0, 0.00001의 정수배
Σ_p x[i,p,m] = C[i,m]                   (모든 사람·월, 공백 A[i,m]을 더하면 B_m)
Σ_m x[i,p,m] = T[i,p]                   (입력된 사람·사업 목표 고정)
허용되지 않은 사업·월이면 x[i,p,m] = 0
Σ_i Σ_m x[i,p,m] ≤ U[p]                 (사업별 연간 상한)
```

연간 합계 `Σ_p T[i,p] + Σ_m A[i,m] = 1.00000`을 배분 전 확인한다. 해당 연도 사업 배정정보가 없거나 0인데 `T[i,p] > 0`이면 오류다. 배정인력 미달은 정상이다.

각 사람마다 `사업(공급량 T) → 허용 월(수요량 C)` 이분 그래프의 정수 흐름 문제로 **실제 실행 가능한 해가 있는지** 판정한다. 사업마다 허용 월이 존재하고 단일 사업의 총 허용 월 용량이 목표 이상인지만 확인해서는 부족하다. 여러 사업이 같은 월에 몰리는 충돌까지 확인해야 한다. 최대 흐름이 사람의 연간 가용량에 못 미치면 `ERROR`이며, 허용 월·목표·부족량을 표시한다. 사업 상한은 목표량 합계로 이미 결정되므로 별도로 사전 검증한다.

## 4. 균등 배분 우선순위와 조정

`E[i,p]`는 사업 수행·제외 월 조건을 통과하고 그 사람의 `C[i,m] > 0`인 월 집합이다. `T[i,p] > 0`인데 `E[i,p]`가 비면 오류다. 목표를 `0.00001` 단위 정수로 바꾼 뒤 허용 월 수 `k`로 나누어 몫 `q`와 나머지 `r`을 구한다. 완전 균등 해에서는 각 허용 월에 `q` 또는 `q+1`단위를 배정하고 정확히 `r`개 월만 1단위 더 받는다. 예를 들어 `0.60000`을 12개월에 배분하면 매월 `0.05000`, 9개월에 배분하면 월별 `0.06666` 또는 `0.06667`이다.

나머지 1단위의 위치는 3·6·9·12월을 우선한다. 여러 사업이 같은 월을 원하면 개인의 정확한 월 가용량을 지키도록 **모든 사업의 나머지를 함께 배치**한다. 분기 말월 안에서는 빠른 월, 나머지 월도 빠른 월 순서로 동률을 처리한다. 예를 들어 연중 사업 A·B의 연간 목표가 각각 `0.50000`이면 각 사업의 월별 값은 `0.04166` 또는 `0.04167`만 사용한다. 분기 말월에는 두 사업이 `0.04167`을 받고 나머지 월에는 둘 중 하나가 1단위 더 받아 월 합계를 맞춘다.

완전 균등 해가 없을 때의 최대 편차는 허용 셀마다 `max(q-x, x-(q+1), 0)`을 계산한 최댓값이다. 최대 편차가 같다면 전체 절대 편차 `Σ |k×x-T|`를 최소화한다. 동률이면 정확히 `0.00010`에 머무는 칸 수를 줄이고, 그다음 분기 말월의 나머지 1단위를 우선한다. 사업은 허용 월 수·약칭, 월은 분기 말월 우선·월 오름차순으로 처리하여 입력 항목 순서와 무관하게 결과를 재현한다.

완전 균등 탐색이나 하한 배분이 실패했다는 이유만으로 `ERROR`를 내지 않는다. 3절의 필수 제약 자체가 불가능할 때에만 배분 불가능으로 판정한다. 제곱편차 최적화는 요구하지 않는다. 휴직이나 제외 월 등으로 불가피한 월별 차이는 허용하며 월별 기준이나 입력 연간 목표는 균등화를 위해 변경하지 않는다.

## 5. 사후 검증과 집계

모든 `x`에 대해 비음수·5자리 단위·허용 월 0, 사람·월 정확한 합계, 사람·사업 연간 목표, 사람·분기 `0.25000`(공백 포함), 사람·연간 `1.00000`(공백 포함), 사업별 상한을 다시 계산한다. 합계를 보존하는 재배치로 월별 최소 배정 부족량을 더 줄일 수 없는지도 음수 순환 검사로 검증한다. 실패하면 결과를 출력하지 않고 `ERROR`다. 개인·사업 월간표와 연간표는 최종 `x`와 `A`에서 합산한다. 분기 합계는 내부 검증에만 사용하고 출력 열에는 포함하지 않는다.

사업1을 4~6월 제외하고 사람의 연간 목표가 사업1 `0.60000`, 연중 허용 사업2 `0.40000`, 공백 없음인 경우, 사업1의 나머지 9개월 평균만 독립 계산하면 월 합계가 어긋난다. 4~6월에는 사업2가 월 가용량 전체를 받고, 그 외 월에는 사업1과 사업2가 함께 월 가용량을 채우는 해를 찾는다.

## 구현의 결정적인 재조정 절차

1. 사람별 `사업 → 월` 정수 최대 흐름으로 필수 제약의 실행 가능성을 먼저 판정한다. 해가 없을 때만 최대 흐름 부족량과 최소 컷의 사업·월을 `E201`로 표시한다.
2. 각 허용 셀에 몫 `q`를 예약하고 최대 `q+1`만 허용하는 흐름을 계산한다. 모든 사업과 월이 동시에 맞으면 완전 균등 해다. 나머지 1단위의 분기 말월 배치를 최소 비용으로 우선한다.
3. 완전 균등이 안 되면 `0.00010` 하한을 예약할 수 있는지 판정한다. 가능하면 허용 셀의 `q-δ…q+1+δ` 범위를 이분 탐색해 실행 가능한 최소 최대 편차 `δ`를 찾는다. 그 범위 안에서 전체 절대 편차·최저값 칸 수·분기 말월 나머지를 순서대로 최소 비용 흐름으로 조정한다.
4. 하한 예약이 불가능하면 먼저 최소치 부족량의 최적값을 구한다. 같은 최적값을 유지하는 최소 `δ`를 탐색하고 같은 절대 편차·동률 규칙을 적용한다. 작은 값과 0을 허용해도 필수 제약은 그대로 지킨다.
5. 합계·목표·허용 월·단위·상한을 사후 검증하고, 독립적인 잔여 그래프의 음수 순환 검사로 최소치 부족을 더 줄일 수 없는지 확인한다. 결과가 올바르면 대상 셀 중 `0.00010` 미만인 월마다 `W006`을 만든다.

모든 흐름 비용과 수량은 정수다. 최저값·절대 편차·최저값 칸 수·분기 말월 선호는 가중치를 분리해 앞선 기준이 뒤의 기준 때문에 바뀌지 않게 한다. `transport(..., minimum=0)` 기본 호출은 하한 없는 배분으로 유지하며 월별 계산 엔진에서 `minimum=10`을 명시한다. 계획 기능은 같은 엔진의 월별 계산·검증을 재사용한다.
