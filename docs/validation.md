# 입력 및 계산 검증

## 판정 원칙

`ERROR`: 잘못된 입력, 논리 불일치, 배분 불가능 또는 내부 계산 불일치. 가능한 독립 오류를 모두 보여준 뒤 **최종 할당표 없이** 실패 종료한다. `WARNING`: 명세대로 해석할 수 있어 계산을 계속할 수 있는 상황. 경고 건수와 적용한 처리 방식을 출력한다. 파일을 읽을 때 무결성을 검사하고, 연도 계산 전과 배분 후에도 재검증한다.

## 검증 단계

| 단계 | 검사와 처리 |
| --- | --- |
| V1 파일 로드 | 파일 없음/읽기 실패, YAML 문법, 중복 mapping 키, 자료형, 미지원 필드 → `ERROR`. `projects.yaml`을 먼저 검증한다. |
| V2 사업 모델 | 정식명 누락/공백, 별칭 누락/중복, `period` 날짜 형식/실재 여부/역전, `yearly` 연도 키, 등록한 연도의 `allocated_manpower` 누락·잘못된 형식, 명시한 `excluded_months`의 잘못된 형식, 배정인력 음수/정밀도 초과, 제외 월 범위 초과 → `ERROR`. `excluded_months` 생략은 `[]`로 처리한다. 제외 월 중복과 수행 기간 밖 연도 정보는 `WARNING`. 0 배정은 파일 수준에서 정상. |
| V3 사람 모델 | `year` 누락/형식, 이름 누락/중복, 공백 기간 누락/형식/역전, 할당 별칭 미존재/중복, 수량 음수/형식/정밀도 → `ERROR`. `absences` 생략/빈 목록, `reason` 생략은 정상. |
| V4 계산 전 | 개인 연간 합계, 대상 연도 사업 배정 상한, 양수 목표의 허용 월 존재 여부, 전체 사업·월 배분 가능성 → `ERROR` 또는 아래 표의 경고. |
| V5 계산 후 | 월·분기·연간 개인 합계, 연간 목표 보존, 금지 월 0, 사업 상한, 5자리 단위 → 불일치 시 `ERROR`. |

## 세부 판정표

| 상황 | 결과 | 처리 |
| --- | --- | --- |
| 휴직 없음 + 연간 사업 할당 합계 ≠ `1.00000` | `ERROR` | 부족/초과량과 사람 이름 출력. |
| 휴직 있음 + `연간 공백 + 연간 사업 목표 ≠ 1.00000` | `ERROR` | 월별 반올림 후 공백량 기준. 임의 보정 금지. |
| 월별 `사업 합계 + 공백 ≠ B_m` | `ERROR` | 결과 폐기. |
| 사업 연간 할당 합계 > 해당 연도 배정인력 | `ERROR` | 사업·연도·상한·초과량 출력. |
| 해당 연도 배정 0 또는 미등록, 양수 할당 목표 없음 | `WARNING` | 사업·연도·0/미등록 구분. 다른 조건 정상 시 계산 계속. |
| 해당 연도 배정 0 또는 미등록, 양수 할당 목표 있음 | `ERROR` | 오류에 0/미등록 상태를 설명하고 최종 계산 중단. 동일 상태를 별도 경고로 중복 집계하지 않는다. |
| 대상 연도에 사업 수행 월 없음/전부 제외, 양수 목표 있음 | `ERROR` | 허용 월 없음 표시. |
| 사업 기간·제외 월·복수 사업 충돌로 배분 불가 | `ERROR` | 충분한 원인 정보와 부족량 출력. 연간 합계가 맞아도 오류. |
| 공백 기간이 대상 연도 밖까지 연장 | `WARNING` | 대상 연도와 교집합만 계산. 전혀 겹치지 않으면 0으로 계산. |
| 공백 기간끼리 날짜 겹침 | `WARNING` | 중복 날짜를 합집합에서 한 번만 계산. |
| 제외 월 목록에 0 포함 | 정상 | 0을 무시한다. `[0, 0, 0]`은 제외 월 없음, `[0, 4]`는 4월만 제외. |
| 0 이외의 제외 월 중복 | `WARNING` | 중복 월을 한 번만 적용. |
| 사업 `yearly`에 수행 기간 밖 연도 등록 | `WARNING` | 파일을 읽을 때 위치를 표시하고 해당 연도에는 할당하지 않는다. |
| 입력 수량이 0 | 정상 | 음수는 오류. 사람이 양수 배분을 모두 0으로 두고 공백이 부족하면 연간 합계 오류. |

`reason`은 선택 정보다. 사업 제외 월 이유는 현재 간단한 월 번호 목록 입력 모델에 포함하지 않는다. 사유 기록이 필요하면 후속 스키마 변경으로 명시적으로 추가한다. 과거 대화의 사업 제외 월별 `reason` 예시는 초안이었다.

사업명은 앞뒤 공백 제거 후 비어 있지 않아야 하며 중간 공백은 유지한다. 사업약칭은 앞뒤 공백 제거 후 비어 있거나 내부 공백이 있으면 `ERROR`다. 사업 목록의 약칭 중복과 사람별 `allocations`의 키 중복은 공백 제거 후에도 검사한다. 참조 및 `--project` 조회에도 같은 규칙을 적용한다. 공백의 범위는 [data-model.md](data-model.md)에 정의한다.

빈 `projects`·`people`, 누락된 `yearly`, 범위 밖 관리 연도·연도 키, 불리언 연도·월은 `ERROR`다. `yearly: {}`와 `allocations: {}`는 구조상 허용하되 대상 연도 배정 및 개인 연간 합계 검증은 그대로 수행한다. 조회 옵션 동시 지정은 CLI 오류다.

숫자 검증은 YAML 파서가 float로 만든 뒤 문자열화해서 수행하지 않는다. `Decimal`은 원문 수치에서 만들고, `0.123456` 같은 6자리 입력은 반올림하지 않고 오류로 처리한다. 날짜 문자열은 4자리 연도와 1~2자리 월·일을 하이픈 또는 점으로 구분한 형식 및 실제 달력 유효성을 검사한다. 점 구분 날짜는 마지막 점도 허용한다. 사업·휴직 모두 같은 규칙이며 구체적인 허용·금지 표기는 [data-model.md](data-model.md#기간의-날짜-형식)를 따른다. 윤년은 내장 달력 규칙으로 계산한다.

## 오류 출력 최소 정보

각 항목은 심각도, 안정적인 오류 코드, 파일/사업/사람/연도/월 중 해당 위치, 현재 값, 요구값, 조치 힌트를 포함한다. 예:

```text
[ERROR E101] people/people_2027.yaml: 홍길동
  사업 목표 합계 0.90000 + 공백 0.00000 = 0.90000
  필요 합계 1.00000, 부족 0.10000
  조치: 입력한 연간 사업 목표를 확인하세요.

[ERROR E201] 김철수: 사업1
  목표 1.00000을 허용 월과 월 가용량 안에 배분할 수 없습니다.

ERROR: 2건 / WARNING: 0건
결과: 계산 중단
```

코드 예시는 범주를 보여주는 것이다. 구현에서는 코드가 실행마다 같은 의미를 가리키도록 문서화한다.

## 구현 오류 코드

| 코드 | 의미 |
| --- | --- |
| E001 | 파일 읽기·UTF-8·YAML 문법·지원하지 않는 YAML 태그 오류 |
| E002 | YAML 원문 mapping의 중복 키 또는 정수 변환 후 중복된 연도 키 |
| E003 | 스키마·필수 필드·자료형·범위 오류 |
| E004 | 이름·약칭의 중복 또는 약칭 내부 공백 |
| E005 | 수량의 형식·부호·정밀도 오류 |
| E006 | 날짜·기간 형식, 존재하지 않는 날짜, 역전 기간 |
| E007 | 등록되지 않은 사업약칭 참조 |
| E008 | 조회 대상 이름·사업약칭 오류 |
| E101 | 개인의 연간 사업 목표와 공백 합계 불일치 |
| E102 | 배정 0·미등록 사업에 양수 목표 존재 |
| E103 | 사업별 연간 배정 상한 초과 |
| E201 | 모든 사업을 함께 고려한 월별 배분 불가능 |
| E301 | 계산 결과의 사후 제약 위반 |
| W001 | 제외 월 중복: 한 번만 적용 |
| W002 | 사업 기간 밖의 연도 배정정보 |
| W003 | 대상 연도 밖의 공백 기간: 교집합만 계산 |
| W004 | 공백 기간 중복: 날짜 합집합으로 계산 |
| W005 | 양수 목표 없는 사업의 배정 0·미등록 |

조회 옵션 조합 등 명령행 문법 오류는 `argparse`의 사용법 설명과 종료 코드 2로 알린다. 파일·계산·조회 대상 오류의 종료 코드는 1이다. 이름·별칭 정렬은 Python 문자열 오름차순을 사용한다. 원문 중복 키는 해당 줄 번호로, 스키마 오류는 파일과 필드 경로로 위치를 표시한다.

YAML은 안전한 로더로 읽으며 임의 객체 태그와 merge key(`<<`)는 지원하지 않는다. 명시적인 필드를 사용한다. 수량은 부호·공백 없이 십진 숫자와 선택적인 소수부 1~5자리로 입력한다. 연도·월은 십진 정수로 입력한다.
