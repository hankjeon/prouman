# 기능 요구사항 및 수용 기준

## 1차 범위

| ID | 요구사항 | 수용 기준 |
| --- | --- | --- |
| R01 | Python 텍스트 기반 CLI, 완전 오프라인 | 인터넷·서버 없이 YAML 두 종류를 읽고 계산한다. |
| R02 | 관리 단위는 한 연도 | people 파일의 `year`로 계산하며 현재 연도에 의존하지 않는다. |
| R03 | 연도별 사람 파일과 공통 사업 파일 | `projects.yaml`에는 다년간 사업, `people/people_YYYY.yaml`에는 한 해의 사람·연간 목표를 둔다. |
| R04 | 한 사람이 여러 사업에 참여 | 사람의 `allocations`에 복수 별칭을 입력한다. 한 사업에도 여러 사람이 참여한다. |
| R05 | 개인 기준 총량 | 개인의 사업 할당량 + 공백 인력은 연간 정확히 `1.00000`, 분기별 정확히 `0.25000`, 매월 해당 월 기준 인력과 같다. |
| R06 | 휴직·공백 | 복수 기간, 월·연도 경계, 윤년을 처리한다. 시작일과 종료일을 포함하고 실제 달력 일수에 비례한다. 중복 날짜는 한 번만 센다. |
| R07 | 사업 수행 기간 | 날짜로 저장하되 시작/종료 월에 하루라도 겹치면 그 **월 전체**를 할당 가능 월로 취급한다. 그 밖의 월은 할당 0이다. |
| R08 | 연도별 제외 월 | 사업별·연도별로 지정한다. 제외 월의 할당은 0이고 사람의 고정 연간 목표는 다른 허용 월로 이동한다. |
| R09 | 사업별 연간 배정인력 | 해당 연도 여러 사람의 할당 합계가 배정인력을 넘지 않는다. 배정인력 미달은 허용한다. |
| R10 | 연간 목표 고정 | 사람별 사업 `allocations`는 입력된 연간 목표다. 알고리즘이 임의로 조정하지 않는다. |
| R11 | 월별 균등 배분 | 사람·사업의 연간 목표를 할당 가능한 월에 우선 균등 분할한다. 월별 합계 등 필수 제약과 충돌하면 연간 목표를 유지한 채 월별 값을 조정한다. 제곱편차의 전역 최적해는 요구하지 않으며, 실행 가능한 입력을 단순 배분 실패만으로 오류 처리하지 않는다. |
| R12 | 소수점 처리 | 모든 수량은 5자리 고정 소수, 최소 단위 `0.00001`; `Decimal`과 `ROUND_HALF_UP`을 사용한다. |
| R13 | 무결성 검사 | 두 YAML 파일을 읽을 때 구조·참조·중복을 확인하고, 배분 전·후에도 계산 제약을 확인한다. |
| R14 | 논리 불일치 | 개인 연간 합계 불일치, 월별 합계 불일치, 사업 상한 초과, 배분 불가능은 모두 `ERROR`다. 임의 보정하지 않는다. |
| R15 | 출력 | 검증 결과, 개인별 월·연간 표, 사업별 월·연간 표와 배정/할당/잔여를 텍스트로 제공하고, 요청하면 같은 내용을 엑셀(.xlsx) 파일로 저장한다. |
| R16 | 실행 결정성 | 동일 입력은 실행 순서·YAML 항목 순서에 관계없이 동일 결과를 낸다. |
| R17 | 데스크톱 GUI | PySide6 화면에서 사업·사람 입력을 YAML 없이 표로 열기·새로 만들기·편집·저장하고, 계산 결과(검증·요약·개인상세·사업상세)를 읽기 전용 그리드로 보여 준다. 계산·검증 규칙과 표시 값은 CLI와 같다. |

## 기준 인력과 집계

각 분기 기준은 `0.25000`이다. 매 분기 첫 두 달은 `0.08333`, 마지막 달(3·6·9·12월)은 `0.08334`다. 따라서 12개월 합계는 `1.00000`이다. 월별 사업 할당 + 월별 공백은 해당 월 기준과 **정확히** 같아야 한다. 분기별 내부 검증과 연간 집계는 월별 결과를 합산한다. 출력 표에는 1~12월과 연간만 표시한다.

입력 연간 목표의 합은 공백 인력의 연간 합계와 함께 정확히 `1.00000`이어야 한다. 휴직이 없으면 사업별 연간 목표 합계가 `1.00000`이어야 한다. 휴직이 있으면 `1.00000 - 연간 공백 인력`이어야 한다. 남거나 넘치는 인력을 자동으로 새 사업에 배정하거나 기존 사업 목표를 바꾸지 않는다.

## 결과 및 실패 동작

기본 출력은 입력 파일·관리 연도, 검증 `ERROR`/`WARNING` 건수, 개인별·사업별 연간 요약이다. `--person`은 특정 인물의 사업별 1~12월 상세와 공백·월 합계, `--project`는 사업의 월별 참여 인력 합계와 연간 배정/할당/잔여, `--all`은 전체 개인별·사업별 상세를 출력한다. `--all-people`은 전체 개인 상세만, `--all-projects`는 전체 사업 상세만 출력하며 두 옵션 모두 전체 연간 요약은 생략한다. `--person`·`--project`에서는 개인별·사업별 전체 연간 요약을 출력하지 않고 선택한 대상의 상세만 출력한다. 사업 상세에는 해당 사업의 연간 배정/할당/잔여를 포함한다. 입력 파일·관리 연도와 검증 결과는 모든 모드에서 표시한다. `--all`은 전체 요약, 전체 개인 상세, 전체 사업 상세를 순서대로 출력한다. 할당이 없는 사업도 사업 상세에 포함하며, 각 요약과 개인·사업 상세 앞에는 빈 줄과 구분선을 넣는다. 이름/별칭 미발견도 오류로 알린다. 모든 성공 출력은 5자리 고정 소수로 표시한다.

`--person`·`--all-people`·`--all`의 개인 상세에는 사업별·공백·합계의 1~12월 및 연간 집계를 포함한다. `--project`·`--all-projects`·`--all`의 사업 상세도 1~12월과 연간만 표시하며 분기별 열은 출력하지 않는다. `--person`·`--project`·`--all-people`·`--all-projects`·`--all`은 상호 배타적이며 동시에 지정하면 오류다. 기본 사업 파일은 실행 작업 디렉터리의 `projects.yaml`이다. 사업명·사업약칭의 공백 처리와 참조 기준은 [data-model.md](data-model.md)를 따른다.

`--excel PATH.xlsx`는 조회 옵션과 함께 쓸 수 있으며, 화면 출력은 조회 옵션을 따르고 엑셀 파일에는 조회 옵션과 관계없이 전체 결과를 저장한다. 시트는 `검증`(관리 연도·입력 파일·검증 건수·이슈 목록), `요약`(개인별·사업별 연간 요약), `개인상세`(사람별 사업·공백·합계의 1~12월·연간 표), `사업상세`(사업별 배정·할당·잔여와 1~12월 할당) 순서다. 수량은 숫자 셀에 정확한 십진 값으로 기록하고 표시 형식은 `0.00000`이다. 합계는 엑셀 수식이 아니라 계산된 값이다. `ERROR`가 있으면 파일을 만들지 않고 종료 코드 1, `WARNING`만 있으면 파일을 만들고 경고를 `검증` 시트에 넣는다. 같은 경로의 파일은 덮어쓴다. 확장자가 `.xlsx`가 아니면 사용법 오류(종료 코드 2), 저장 실패(파일이 열려 있음 등)는 종료 코드 1이다. 엑셀이 파일을 열 때 숫자 셀을 배정밀도로 읽으므로, 엑셀 안에서 다시 계산한 값은 5자리 고정 소수 결과와 미세하게 다를 수 있다. 기준 값은 텍스트·셀에 기록된 값이다.

GUI는 사업 파일 경로를 사용자가 직접 고른다(CLI는 작업 디렉터리의 `projects.yaml`). 사람 파일을 열 때 사업 입력이 편집 중이 아니고 사업 파일 칸이 비어 있거나 직전에 자동으로 연 파일이면, 사람 파일 폴더와 바로 위 폴더 순서로 `projects.yaml`을 찾아 연다.

GUI의 `사업 입력` 탭은 사업명·약칭·시작일·종료일과 선택한 사업의 연도별 배정인력·제외 월을, `사람 입력` 탭은 관리 연도, 사람 × 사업 참여율 표, 선택한 사람의 휴직 기간(시작일·종료일·사유)을 편집한다. 편집기는 입력한 문자열을 그대로 보관하고, 생성·저장할 때 YAML로 만든다. **생성은 저장하지 않은 현재 입력 내용**을 파일과 같은 `load_inputs` 검증(위치 표시는 파일 경로, 새 파일은 `(새 사업 파일)`·`(새 사람 파일)`)과 계산에 넘긴다. 편집기는 계산·검증 규칙을 따로 두지 않으며, 입력 중에는 형식 오류 칸(날짜, 수량 형식, 연도·제외 월, 사업명·약칭 누락, 약칭 공백·중복, 사람 이름 누락·중복, 사업 목록에 없는 약칭)과 사업 합계 + 공백 ≠ `1.00000`인 사람의 합계 칸만 안내한다. 공백은 계산 엔진과 같은 월별 반올림으로 구한다. 사업 약칭을 바꾸면 그 약칭이 이 사업에만 쓰였고 새 약칭이 다른 사업과 겹치지 않을 때 사람 참여율 키도 바꾼다. 참여율이 있는 사업을 지우면 확인을 받고 해당 참여율도 지운다. 사업 목록에 없는 약칭의 참여율은 `(미등록)` 열로 남겨 값이 사라지지 않게 한다.

저장은 문서 모델에서 YAML을 새로 써서 원래 파일의 주석과 서식을 유지하지 않는다. 이름·약칭·기간·수량은 큰따옴표 문자열, 연도와 제외 월은 정수로 쓰며(숫자가 아니면 문자열로 써서 같은 검증 오류를 받는다), 빈 참여율 칸은 쓰지 않는다. 같은 실행에서 기존 파일을 처음 덮어쓰기 전에 원본을 `파일이름.bak`으로 복사한다. 파일을 열 때 알 수 없는 필드와 중복 키는 편집기가 다루지 않으므로 목록을 알려 주고, 저장하면 빠진다. YAML 문법 오류나 목록·mapping 구조가 맞지 않는 파일은 편집기로 열지 않고 사유를 알린다. 저장하지 않은 변경은 탭 이름의 `*`로 표시하고, 다른 파일을 열거나 새로 만들거나 창을 닫을 때 저장·버리기·취소를 묻는다. 편집기 형식으로 읽고 다시 쓴 파일은 원본과 같은 입력·결과·진단을 만들어야 한다(T30).

생성 결과는 `검증`·`요약`(개인별·사업별 연간 요약)·`개인상세`(사람 목록에서 고른 사람의 사업·공백·합계 1~12월·연간 표)·`사업상세` 탭에 표시하며 엑셀 시트와 같은 표 데이터를 쓴다. 수량은 5자리 고정 소수 문자열로 오른쪽 정렬한다. 로드 실패나 `ERROR`가 있으면 검증 탭만 채우고 결과 탭을 비우며 엑셀 저장을 막는다. `WARNING`만 있으면 결과를 표시한다. 엑셀 저장은 `--excel`과 같은 파일을 만들고, 저장 실패는 경고 대화상자로 알린다. 그리드에서 선택한 셀은 포커스와 관계없이 같은 배경색으로, 현재 셀은 테두리로 표시하고, Ctrl+C로 탭 구분 텍스트(표시 문자열 그대로, 선택하지 않은 칸은 빈 칸)로 복사한다. 마지막으로 열거나 저장한 두 파일 경로는 사용자 설정(QSettings)에 저장해 다음 실행 때 다시 연다. 글자 크기는 기본 10pt이며 `보기` 메뉴와 Ctrl + `+`·`=`/`-`/`0` 단축키로 7~24pt 사이에서 바꾸고, 행 높이·열 너비를 새 크기에 맞춘다. 사용자가 바꾼 크기만 사용자 설정에 저장한다.

가능한 검증 오류를 한 번에 모아 출력하되, 의미 없는 후속 검증은 건너뛴다. `ERROR`가 하나라도 있으면 최종 할당표를 생성하지 않고 종료 코드 0이 아닌 값으로 끝낸다. `WARNING`만 있으면 계산을 계속하며 종료 코드는 0이다. 출력용 통계는 해에서 다시 집계한다.

## 오프라인 의존성 준비

실행 시 외부 통신을 요구하지 않는다. 외부 패키지를 도입하면 버전을 고정하고, 인터넷이 가능한 환경에서 wheel을 준비한 뒤 오프라인 환경에서 해당 파일만으로 설치하는 절차를 제공한다. 오프라인 설치와 실행은 각각 검증한다.

## 2차 이후 범위

사람별 참여 사업과 우선순위를 입력하여 **사업별 연간 참여율 자체**를 자동 결정하는 기능은 2차다. 1차의 계산 엔진은 독립 모듈로 두어 그래프·CSV 출력이 나중에 추가될 수 있게 한다. 엑셀(.xlsx) 저장과 PySide6 데스크톱 GUI는 1차 범위에 포함한다. 실행 파일(exe) 패키징은 범위 밖이다. 1차에 우선순위 필드나 월별 직접 입력 형식을 추가하지 않는다.
