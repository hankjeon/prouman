# 개발 기록

## CLI 사업별 참여자 상세

- 목표: CLI 사업 상세에서 참여자별 월 할당과 연간 합계를 사업 전체 합계와 함께 표시한다. GUI와 엑셀 변경은 범위 밖이다.
- 결정: 연간 할당이 양수인 사람만 이름순으로 표시한다. 0 목표는 실질 참여가 아니므로 제외한다. 참여자가 없는 사업도 기존 0 합계 행을 유지한다. 계산 엔진의 정수 결과를 그대로 사용해 월별·연간 합계를 산출한다.
- 작업: `--project`, `--all-projects`, `--all` 출력과 요구사항·README·회귀 테스트를 갱신했다. 기준 커밋은 `675535e`; 관련 변경 커밋은 Git 이력에서 확인한다.
- 검증: 기능 추가 전 신규 테스트가 세 조회 옵션에서 참여자 행 누락으로 실패했고, 구현 후 통과했다. `/home/hank/work.py/prouman/.venv/bin/python -m unittest discover -s tests -v`에서 73개 테스트 통과. GUI 테스트에서 Qt offscreen 플러그인 경고가 출력됐다.
- 남은 작업: 없음. GUI 참여자별 상세는 아래 후속 기록을 참조한다.

## GUI 사업별 참여자 상세

- 목표: GUI에서도 사업별 참여자의 월별·연간 할당을 조회한다.
- 결정: 개인 상세와 동일하게 왼쪽 사업 목록과 오른쪽 참여자 상세를 배치하고, 오른쪽 위에 선택 사업의 배정·할당·잔여를 표시한다. CLI와 동일하게 양수 할당자만 이름순 표시하고 비어 있는 사업에도 0 합계를 표시한다. 엑셀 형식은 변경하지 않는다.
- 작업: CLI와 GUI의 참여자 목록 집계를 공통화하고 선택·복사·오류 시 초기화 테스트를 추가했다. 기준 커밋은 `0119efb`; 관련 커밋은 Git 이력을 참조한다.
- 검증: 기능 추가 전 GUI 테스트는 관련 화면 구성 요소가 없어 실패했고 구현 후 통과했다. `.venv/bin/python -m unittest discover -s tests -v`에서 74개 통과. Qt offscreen 경고가 출력됐다.
- 남은 작업: 없음. 사용자 화면 확인 완료.

## Bash 가상환경 활성화

- 목표: 저장소 `.venv`를 쉽게 활성화한다. 기준 커밋은 `0119efb`이며 관련 커밋은 Git 이력에서 확인한다.
- 결정 및 작업: `source ./venv.sh`는 현재 Bash에 적용하고, 직접 실행은 활성화된 자식 Bash를 연다. 환경이 없으면 생성·설치 안내만 하고 자동 설치하지 않는다.
- 검증: 활성화·중복 실행·다른 환경 전환·없는 환경·직접 실행을 검증했다. 전체 테스트 78개 통과, `bash -n venv.sh` 통과.
- 남은 작업: 없음.

## GUI 결과 화면 자동 계산

- 목표: 생성 버튼 없이 결과 화면을 열 때 현재 입력으로 바로 계산해 보여 준다. 기준 커밋은 `5476d1c`이며 관련 커밋은 Git 이력에서 확인한다.
- 결정: 예제 입력 기준 계산이 0.001~0.005초로 측정돼 탭 전환 시 계산해도 부담이 없으므로, 입력 화면의 생성 버튼과 결과 화면의 다시 생성 안내·대기 문구를 없앴다. 결과 메뉴·Ctrl+2·보기 메뉴로 결과 화면에 갈 때마다 저장하지 않은 현재 내용을 `load_inputs`·`calculate`로 계산한다. 오류면 검증 탭과 돌아오기 안내를 보여 준다.
- 작업: `show_page`에서 결과 화면 이동 시 계산하고, `generate`는 직접 결과 화면으로 전환한다(재귀 없음). 머리 줄 시각 표기를 `생성`에서 `계산`으로 바꾸고 요구사항·README·테스트 케이스·안내 문구를 갱신했다.
- 검증: 신규 자동 계산 테스트가 구현 전 실패·후 통과했다. 전체 테스트 79개 통과. Qt offscreen 경고가 출력됐다.
- 남은 작업: 없음.

## 사업 입력 연도 표 스크롤바·6열

- 목표: 우측 연도별 배정인력 표를 6열로 보이고, 제목 줄 ◀ ▶ 대신 표 아래 스크롤바로 연도 창을 옮긴다. 기준 커밋은 `5476d1c`이며 관련 커밋은 Git 이력을 참조한다.
- 결정: 처음 창은 관리 연도가 왼쪽에서 세 번째(짝수 6열의 중앙 앞쪽)에 오도록 둔다. 스크롤 범위는 배정 연도 구간과 현재 창을 함께 덮고, 양옆 ◀ ▶ 버튼은 1년씩 밀어 빈 연도까지 볼 수 있다. 제외월 열은 연도 열의 1.4배로 넓히고(연도 열 등간격 유지), 제외월 머리글 강조색은 없앴다. 좌우 표 높이를 맞추려고 왼쪽에 스크롤 줄과 같은 높이 여백을 두었다.
- 검증: 신규 스크롤바·6열 테스트가 구현 전 실패·후 통과했고, T30·T32 기대값을 6열 기준으로 갱신했다. 전체 테스트 84개 통과. Qt offscreen 경고가 출력됐다.
- 남은 작업: 없음.
