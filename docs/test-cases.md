# 수용 테스트 사례

이 문서의 T01~T34는 현재 구현된 월별 배분·GUI의 수용 사례다. 후속 연간 인력 계획의 P01~P12는 [계획 기능 명세](annual-planning.md#수용-사례)에 정리했으며 아직 실행 테스트가 아니다.

실제 테스트는 임시 YAML을 생성해 CLI와 계산 함수를 검증한다. **기대 수치는 5자리 고정 소수 문자열**로 비교하고, 연간 합계만이 아니라 월별·분기별 제약도 확인한다. 모든 성공 사례에서 동일 입력 반복 및 YAML 사업/사람 순서 변경 후 결과가 같아야 한다.

추가 날짜 형식 수용 사례: 사업·휴직 기간에 `YYYY-MM-DD`, `YYYY-M-D`, `YYYY.M.D`, `YYYY.M.D.`를 사용하고 시작·종료 표기를 조합해도 같은 계산 결과를 얻어야 한다. 점 표기 윤일과 같은 날의 시작·종료를 허용한다. 존재하지 않는 날짜, 역전 기간, 한 날짜 안의 구분자 혼용, 슬래시, 중복 끝 점, 하이픈 표기의 끝 점, 누락·추가 기간 구분자는 `E006`으로 거부한다.

## 월별 최소 배정 추가 수용 사례

- A 목표 `0.08000`·허용 월 `[2,6,8,10]`, B 목표 `0.71000`·허용 월 `[1,3,5,6,7,8,9,10,11,12]`, 연중 목표 `0.21000`·12개월 허용: 모든 허용 셀이 `0.00010` 이상이며 W006 없음. 기존 조정에서 생기던 불필요한 0을 방지한다.
- 기간사업이 1월에만 `0.08333`, 연중 사업이 `0.91667`인 사람: 연중 사업 1월만 0과 W006, 나머지 월은 최소치 이상. 기간사업 목표가 `0.08328`, 연중 목표 `0.91672`이면 1월 연중 배정은 `0.00005`이고 다른 월은 유지한다.
- 연중 사업 A=`0.00060`, B=`0.99940`: A는 매월 `0.00005`와 W006, 연간 목표 유지. A가 `0.00001`뿐인 경우 0인 월도 허용하되 정확한 연간 목표 유지.
- 연간 목표 0인 사업, 제외 월·기간 밖·개인 전체 공백 월에는 최소치와 W006을 적용하지 않는다.
- 작은 문제 400개를 완전 탐색해 실행 가능성, 최소치 부족량 합계, 동률의 균등 초안 편차, 항목 순서 독립성을 비교한다. 기존 하한 없는 흐름 200개 비교도 유지한다.
- 행·열 합계는 맞지만 최소치 부족을 더 줄일 수 있는 해를 사후 검증에 넣으면 E301이다.

## 계산 검증 방법

T02·T03은 각 사람·사업의 연간 목표뿐 아니라 **모든 월의 정확한 합계와 허용 월의 값**을 검사한다. 제곱편차의 최솟값이나 다른 실행 가능한 해보다 더 균등한지까지 검사하지 않는다. 같은 입력을 반복하고 YAML의 사업·사람 순서를 바꾸어도 같은 결과가 나와야 한다. T11·T12는 간단한 분할의 성공 여부가 아니라 실제 배분 가능성에 따라 오류를 판정하는지 확인한다.

T06의 정답은 `0.08333 / 29 = 0.002873...`이므로 `0.00287`, 따라서 연간 가용량은 `0.99713`이다. T05의 7월 공백 `0.04570`과 T06의 2월 공백 `0.00287`은 윤년·정밀도 회귀 검사다. 실제 사람·사업 수가 늘어난 경우에도 정수 단위의 제약 검증을 모든 결과에 적용한다.
